# Instructions for agents

This repo holds site editing prototypes for a project to make the WordPress.com Site Editor easier for new users.

1. **Read [PLAN.md](PLAN.md) before doing anything.** It's the source of truth for the project: the goal, the constraints, who decides what, and what's next.
2. **Follow its "Who does what" rules.** Ask Ben before touching Gutenberg or CNL trunk, publishing on a P2, contacting participants, spending money, or changing the plan's Goal or Constraints.
3. **Name new experiments by the convention in the README:** one folder per experiment, named after an artist's surname, in alphabetical order. Add each new experiment to the README's list.
4. **Run the removability check** on any experiment that is a WordPress plugin before it goes in front of users (see PLAN.md).
5. **When you finish a piece of work, add a line to the Status log in PLAN.md** (newest first): what changed and what's next. Update the Scorecard if results changed.
6. Keep PLAN.md current rather than relying on chat history: the next agent only knows what's written there.
