# site-editing-experiments

Prototypes exploring site editing interactions. Each experiment lives in its own folder, named after an artist, in alphabetical order as they're added (Albers, Bourgeois, Cassatt, and so on). Most are plain HTML, CSS and JavaScript, served with GitHub Pages; WordPress plugins say so and explain how to run them.

## Experiments

- [Albers](albers/), section editing modes: add, move and delete sections, and hover a section to edit its layout from presets and add or remove items, edit its content in place, or move and resize items freely with grid and snap guides.
- [Bourgeois](bourgeois/), the Section Site Editor WordPress plugin: turns the real site editor into a section-by-section editor, with a section menu and Add a Section picker, Edit section and View layouts panels, ten section colour themes on a five-colour palette, Site Styles, and Freeform sections where you click and drag blocks on a snap grid, with a separate mobile layout.
- [Cassatt](cassatt/), mobile section editing: the same ideas reworked for phones. Tap a section to select it, then use the bottom toolbar and sheets to change its layout and colours, edit its content, drag items into a new order, and add, move, duplicate or delete sections. A Phone | Desktop switch shows the same page at desktop width, where it can be edited too.
- [Degas](degas/), Albers on real blocks, a WordPress plugin: hover a section in the editor for Edit layout (preset layouts with live previews, and colour palettes), Edit content (text and images in place, everything else locked) or Freeform (drag and resize on a grid with snap lines, saved on the blocks), plus Add, an Add section picker of twelve section types, and move, duplicate and delete. [Try it in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Automattic/site-editing-experiments/trunk/degas/blueprint.json).
- [Escher](escher/), writing and design toolbars: instead of one toolbar for everything, a Word-style writing toolbar for text (style, font and size, all presets that swap the block underneath) and a PowerPoint-style design toolbar for moving things and changing section layouts, with live layout previews.
- [Frankenthaler](frankenthaler/), one block toolbar in a fixed order, a Gutenberg pull request behind an experiment: the block's icon for transforms and style presets, bigger movers, a labelled Layout and `+` for containers, one searchable options menu with labelled flyouts (Align, Format, Styles, Insert, More), a trash button on every block, a parent selector outside the toolbar so it never moves, and formatting in its own toolbar that appears with a text selection. [Gutenberg PR](https://github.com/WordPress/gutenberg/pull/85187). [Try it in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Automattic/site-editing-experiments/trunk/frankenthaler/blueprint.json).
- [Hepworth](hepworth/), Escher's toolbars as a WordPress plugin: every block's toolbar gets a Write / Design switch. Writing shows Word-style Style, Font and Size menus built from the theme, where every font and size is a block transformation underneath, plus a size of your own and font colour; designing shows the editor's movers and settings for buttons, pictures and sections. Changing a colour asks whether to use it for every heading, button or section. [Try it in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Automattic/site-editing-experiments/trunk/hepworth/blueprint.json).
- [Ito](ito/), change the layout and keep the content, a WordPress plugin: hover a section for Edit layout, which previews layouts made from the section's own blocks (stacked, centred, picture beside or behind, one fewer or more column, grid shapes), with its own words and pictures. Pick one and the layout changes, and no content block is added or removed. [Try it in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Automattic/site-editing-experiments/trunk/ito/blueprint.json).
- [Judd](judd/), making a website from first principles: instead of templates and blocks, the site is a model of the thing it's about (a pottery studio's facts, classes, shop and news) and pages are views over it. Edit anything in place and it tells you where else it appears, asking every page or just this one for shared things; the look is a few taste dials; a command bar takes plain sentences; a To do list catches what's gone stale; drafts, compare and history make it safe to experiment; and the same content makes a newsletter, a social post, a search listing and data for AI agents.
- [Klee](klee/), a generated website you can edit by hand: the site is never stored, only its inputs (a brief, opinions in your own words and your direct edits), and a cached, hashed pipeline rebuilds the same page from them every time. Click any text to change it and that edit becomes an input that always wins; say "calmer" or "too busy" about the site or one section and review what changes, section by section, before keeping it; repeated edits are offered back as rules for the whole site. Also: Why? on every section, other takes from new seeds, and a model upgrade you review like any other change.
- [Lowry](lowry/), the site editor as [WebMCP](https://github.com/webmachinelearning/webmcp) tools, a WordPress plugin: an agent in the browser edits through the editor itself, so every change is live on the canvas, can be undone and isn't saved until you save. Select a block and the agent gets tools made for it from its `block.json` and the theme's presets; content edits happen straight away, and design changes open the section first, as Edit section does. The tools are abilities, so WordPress' own and other plugins' are offered too. An Agent panel asks Claude, lists the tools as they change and logs every call. [Try it in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Automattic/site-editing-experiments/trunk/lowry/blueprint.json).
- [Morris](morris/), font and size in the block toolbar, a Gutenberg pull request behind an experiment: every block with typography gets Font and Size menus that name what it's shown in now (a heading says "Manrope · 28"), with the theme's fonts in their own typefaces, its sizes at their real size, a size of your own, and Default to go back to the theme. Escher's writing toolbar without the mode switch. [Gutenberg PR](https://github.com/WordPress/gutenberg/pull/86248). [Try it in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Automattic/site-editing-experiments/trunk/morris/blueprint.json).
- [Nevelson](nevelson/), block settings beside the block, a WordPress plugin: Judd's popovers in the real editor. Select a block and the editor's own block inspector opens in a floating card beside it and follows it as you scroll; drag it somewhere else if you'd rather. It's always the clicked block's own settings, even inside a pattern or template part. There's no sidebar: the page's settings open in a card from the Settings button. On a narrow screen the panel is a sheet along the bottom. [Try it in Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Automattic/site-editing-experiments/trunk/nevelson/blueprint.json).
