# site-editing-experiments

Prototypes exploring site editing interactions. Each experiment lives in its own folder. Most are plain HTML, CSS and JavaScript, served with GitHub Pages; WordPress plugins say so and explain how to run them.

## Experiments

- [Section editing modes](section-editing-modes/): add, move and delete sections, and hover a section to edit its layout from presets and add or remove items, edit its content in place, or move and resize items freely with grid and snap guides.
- [Section Site Editor](section-site-editor/) (WordPress plugin): turns the real site editor into a section-by-section editor, with a section menu and Add a Section picker, Edit section and View layouts panels, ten section colour themes on a five-colour palette, Site Styles, and Freeform sections where you click and drag blocks on a snap grid, with a separate mobile layout.
- [Mobile section editing](mobile-section-editing/): the same ideas reworked for phones. Tap a section to select it, then use the bottom toolbar and sheets to change its layout and colours, edit its content, rearrange or add items, and add, move, duplicate or delete sections.
