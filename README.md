# site-editing-experiments

Prototypes exploring site editing interactions. Each experiment lives in its own folder. Most are plain HTML, CSS and JavaScript, served with GitHub Pages; WordPress plugins say so and explain how to run them.

## Experiments

- [Section editing modes](section-editing-modes/): add, move and delete sections, and hover a section to edit its layout from presets and add or remove items, edit its content in place, or move and resize items freely with grid and snap guides.
- [Squarespace-style site editor](squarespace-style-site-editor/) (WordPress plugin): makes the real site editor look and work like Squarespace's, with its section menu and Add a Section picker, Edit section and View layouts panels, ten section colour themes on a five-colour palette, Site Styles, and Freeform sections where you click and drag blocks on a snap grid, with a separate mobile layout.
