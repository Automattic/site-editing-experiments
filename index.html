Site editing experiments

Prototypes exploring site editing interactions.

  • Albers Section editing modes Add, move and delete sections. Edit a section's layout from presets and add or remove items, edit its content in place, or move and resize them freely with guides.
  • Bourgeois Section Site Editor A WordPress plugin, not a mockup: the real site editor, section by section, with colour themes, Site Styles and freeform grid sections. Opens the plugin's README on GitHub.
  • Cassatt Mobile section editing The same ideas reworked for phones: tap a section, then use the bottom toolbar and sheets to edit layout, colours and content, and drag items into a new order. Switch to Desktop to check, and keep editing, the same page on a big screen.
  • Degas Section editing modes on real blocks A WordPress plugin that brings Albers' Edit layout, Edit content and Freeform into the real editor. Opens a live demo running in WordPress Playground, in your browser.
  • Escher Writing and design toolbars Two toolbars instead of one: a Word-style one for writing, where fonts and sizes are theme presets that quietly change the block underneath, and a PowerPoint-style one for moving things and picking layouts.
  • Frankenthaler One block toolbar, in a fixed order A Gutenberg pull request: the block's icon for transforms and style presets, bigger movers, Layout and + for containers, one searchable options menu with labelled flyouts, a parent selector that never moves the toolbar, and formatting that appears with a text selection.
  • Hepworth Writing and design toolbars in WordPress A WordPress plugin, not a mockup: Escher's two toolbars in the real editor, with fonts and sizes that are block transformations underneath. Opens a live demo running in WordPress Playground, in your browser.
  • Ito Change the layout, keep the content A WordPress plugin: Edit layout shows a section in other layouts made from its own blocks, previewed with its own words and pictures. Picking one changes the layout, and no content is added or removed. Opens a live demo running in WordPress Playground, in your browser.
  • Judd Making a website from first principles No templates or blocks: the site is a model of a pottery studio, and pages are views of it. Edit in place and see everywhere it appears, set the look with a few dials, say what you want in plain words, fix what's gone stale, experiment in a draft, and see the same content as a newsletter, a post, a search listing and data for AI agents.
  • Klee A generated website you can edit by hand The site is made from a brief, your opinions and your edits, and rebuilt from them the same way every time. Change any text directly and it always wins; say what you think and review each change before keeping it.
  • Lowry The site editor as WebMCP tools A WordPress plugin: an agent in the browser edits the page through the editor itself, live on the canvas, undoable and unsaved until you save. Select a block and the tools change to fit it. Opens a live demo running in WordPress Playground, in your browser.
  • Morris Font and size in the block toolbar A Gutenberg pull request: every block with text gets Font and Size menus that name what it's shown in now, with the theme's fonts in their own typefaces, its sizes at their real size, and a size of your own. Escher's writing toolbar without the mode switch.
