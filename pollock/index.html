Drag handles

The block editor already uses the six-dot drag handle, but people don't see it as one: it's a narrow button in the toolbar with tiny dots, pressed against the move arrows. These three prototypes are the same page in the same editor with only the handle changed, so a test can tell whether the problem is where the handle is or how it looks.

  • A · TodayControl: the toolbar handle as the editor draws itA 24px-wide button with the icon clipped inside it, between the block icon and the move arrows. Tab skips it.
  • B · On the block's edgeWhere people expect a handleA six-dot grip beside the block's first line, shown when you hover a block and on the selected one. The toolbar keeps its move arrows. Arrow keys move the block when the grip has focus.
  • C · Bigger, in the toolbarSame place, made legibleToday's handle as a full-size button with dots you can see, in its own group at the start of the toolbar, with a tooltip. Tab reaches it, and arrow keys move the block.

Round 2
