# Section editing modes

A clickable mockup exploring three ways to edit a section of a page. Hover any section to get an overlay with three choices:

- **Edit layout:** a floating panel at the top of the section offers preset arrangements, each with a small diagram, and the section changes underneath as you pick. The toolbar also adds new items suited to the section, such as a heading, paragraph, button or image in the hero, or a new card in features, and every item gets a bin button to remove it. **Restore removed** brings back what you took out. New items work in the other modes too, so you can edit, move and resize them.
- **Edit content:** text becomes click-to-edit and each image gets a "Replace image" button. Nothing can be moved.
- **Freeform:** every item can be dragged anywhere and resized, and text and images are locked. Click an item to select it: images and cards get handles on every side and corner, and text gets left and right handles so it reflows. While you move or resize:
  - A 12-column grid and centre line show behind the content.
  - Pink snap lines appear when an item's edge or centre lines up with another item, the section centre or the content edges.
  - The **Grid** and **Snap to guides** buttons turn each of these off, and **Reset positions and sizes** puts the section back.

## Adding and arranging sections

- **Add a section:** hover a section and click one of the **Add section** buttons on its top or bottom edge. A space opens between the sections with a picker of eight section types: Hero, Features, Call to action, Text, Image, Gallery, Quote and Contact; **Cancel** closes it again. New sections start with placeholder copy and photos, and work with every editing mode.
- **Move a section:** hover it and use the up and down arrows in its top-right corner.
- **Delete a section:** use the bin in the same corner. A message at the bottom of the page lets you undo it.

Only one section is in a mode at a time. **Done** leaves the mode, and **Reset everything** in the top bar reloads the original page.

## Sections and layouts

| Section | Layouts |
| --- | --- |
| Hero | Split, Centered, Image left |
| Features | Three columns, Stacked list, Featured + two |
| Call to action | Centered, Split, Dark banner |
| Text | Single column, Centered, Two columns |
| Image | Contained, Full width, With caption |
| Gallery | Three across, Two across, Mosaic |
| Quote | Centered, Left aligned, Dark band |
| Contact | Split, Stacked, Card |

## Running it

It's plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser or serve the folder with any static server.
