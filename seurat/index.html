Where do the typography controls live?

In the WordPress editor, the controls that change a block's font, size and line spacing are in the settings sidebar, and most of them are hidden until they're turned on. These four prototypes are the same page in the same simple editor, with the same seven typography controls, and differ only in where those controls are, so a test can tell whether people find them more easily on the toolbar.

  • 0 · ControlAs the WordPress editor is todayTypography is in the sidebar's Block tab. Only Size shows; Font, Line height and the rest are turned on from the panel's options menu.
  • A · On the toolbarArranged the way Squarespace arranges its text toolbarA text style menu, then Font and Size, each naming what the text is set in now, with the rest under "More text options".
  • B · In the options menuAfter the block toolbar proposal in Gutenberg issue #85204The toolbar is block name, movers, options and delete. Typography is a labelled flyout in one searchable options menu, and formatting appears when text is selected.
  • C · Beside the blockAfter NevelsonA pencil on the toolbar opens the block's settings in a card beside it, with the same Typography panel as the control. There's no sidebar.
